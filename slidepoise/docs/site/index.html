How SlidePoise works

The Agent develops what each slide needs to say and how its ideas relate. Image generation explores the composition, typography and imagery that express those ideas. To rebuild the chosen image in PowerPoint, the Agent identifies what each element represents and how it relates to the others, while OpenCV measures its geometry. Reconstruction tools combine this interpretation and measurement to create editable text, charts and diagrams.

Develop a style together with the Agent using visual references and feedback. Ask it to save your choices as a reusable profile for future presentations, and refine it as your needs change. The optional local Console lets you inspect and adjust the same settings and asset libraries. Profiles and libraries are saved on your computer.

Open the local Console

After installation, ask Codex to open the SlidePoise Console, or run this command in a terminal.

npx github:henryhyw/slidepoise console

The Console opens in your browser and saves settings on your computer. Saved changes apply to future presentations. Ask Codex to update a presentation already in progress.

What gets installed

Setup installs measurement and PowerPoint tools, registers the Codex skill, and prepares local slide previews. Your system may request administrator access for the preview tools.

  • An isolated Python environment in ~/.slidepoise/python with Pillow, python-pptx, NumPy and OpenCV.
  • PptxGenJS and JSZip in ~/.slidepoise/node.
  • Profiles and Library Sets in ~/.slidepoise, with the skill registered in ~/.codex/skills/slidepoise.

LibreOffice renders the PowerPoint and Poppler converts it into images for the Agent to review. Setup installs missing copies through Homebrew on macOS, winget on Windows, or apt on Debian/Ubuntu. Codex supplies image generation.
