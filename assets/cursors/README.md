The zoom cursors use Font Awesome Free 6.7.2 magnifying-glass by Fonticons, Inc., copyright 2024. The original path is unchanged. These versions add a contrasting outline, light and dark colours, a padded viewBox and a 24 px cursor size.

[Original icons](https://github.com/FortAwesome/Font-Awesome/tree/6.7.2/svgs/solid) are licensed under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). [Font Awesome licence](https://fontawesome.com/license/free).

The text cursors are original site artwork. Their 24 px I-beam uses a 1.5 px stem, small curved shoulders and the same contrasting outline weight as the site arrow. The pointer hotspot is at its centre.
